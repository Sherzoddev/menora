# Menora — печать чеков на кухне

Программа для **Windows**-компьютера рядом с чековым принтером (HP80 / POS-80
/ любой ESC/POS-принтер по USB), которая автоматически печатает чек, как
только клиент оформляет заказ — с сайта, из Telegram-бота или через QR на
столе, неважно откуда.

Она нужна, потому что сам сайт работает в облаке и физически не видит USB-порт
компьютера на кухне — печатать может только программа, которая стоит
непосредственно на этом компьютере.

## Установка (для владельца заведения)

Нужна папка с `Menora.vbs`, `menora-print.exe`, подпапками `gui` и
`node_modules`. Ничего кроме них ставить не нужно (ни Node.js, ни PowerShell
отдельно — он уже есть в любой Windows).

1. Скопируйте всю папку на компьютер рядом с принтером.
2. Запустите **`Menora.vbs`** двойным кликом. Откроется обычное окно
   программы (никакого чёрного окна консоли).
3. При первом запуске окно спросит:
   - **Email и пароль** от кабинета Menora (тот же, что на `/cabinet/login`
     на сайте).
   - **Ссылку на ваше меню** (или просто её последнюю часть — slug).
   - **Как подключён принтер** — три кнопки-переключателя:
     - **Windows** — принтер уже установлен в Windows (по USB через родной
       драйвер). Программа сама находит все такие принтеры и показывает их в
       выпадающем списке. Самый надёжный вариант, если драйвер принтера есть.
     - **USB** — печать напрямую в USB-порт принтера, в обход Windows и
       драйверов вообще. Пригодится, если у дешёвого принтера нет нормального
       Windows-драйвера. Список USB-устройств обновляется кнопкой рядом.
     - **Bluetooth** — принтер подключён по Bluetooth (сначала его нужно
       сопрячь через Bluetooth-настройки Windows — программа не делает это
       сама). После сопряжения он появится в списке как COM-порт.
   - **Кодировка кириллицы** — выпадающий список из всех вариантов, которые
     умеют дешёвые ESC/POS-принтеры (PC866, Windows-1251, PC855 и т.д. — см.
     раздел «Кириллица печатается кракозябрами» ниже). Если не уверены —
     оставьте значение по умолчанию и проверьте кнопкой «Тестовая печать».
   - **Запускать при включении компьютера** — галочка, включена по
     умолчанию.
   Кнопка «Тестовая печать» проверяет выбранное устройство прямо в этом
   окне, ещё до сохранения остальных полей.
4. Кнопка «Сохранить и запустить» — окно закроется, а программа свернётся в
   **значок в трее** (у часов, внизу справа) и будет ждать заказы в фоне.

### Как снова открыть окно настроек

- **Дважды кликните** по значку Menora в трее (у часов, внизу справа) — это
  самый быстрый способ. Если значок не видно, разверните скрытые значки
  стрелкой рядом с часами.
- Или через **Пуск** — программа при первом запуске сама создаёт там ярлык
  «Menora — печать чеков», который открывает окно настроек, даже если трей
  скрыт и найти значок не получается.
- Правый клик по значку в трее тоже открывает то же меню: «Настройки» и
  «Выход».

**Важно:** это Windows-программа — на телефоне или планшете (Android/iOS)
она не запустится, там принципиально другой способ печати (отдельное
мобильное приложение, см. `android-app/`).

## Как это работает

1. Программа один раз входит в тот же кабинет заведения, что и
   `/cabinet/login` на сайте.
2. Подписывается на новые заказы этого заведения через Supabase Realtime —
   без постоянного опроса сервера, заказ печатается практически мгновенно.
3. Формирует чек и отправляет его на принтер одним из трёх способов —
   смотря что выбрано в настройках (см. `printer-transport.js`):
   - **Windows** — через официальный API диспетчера печати
     (`winspool.drv`/`RAW`), тот же приём, что использует десктопное
     приложение Velora. Не нужен общий доступ к принтеру — работает с уже
     установленным в Windows принтером напрямую.
   - **USB** — сырые ESC/POS-байты прямо в USB bulk-эндпоинт принтера, в
     обход Windows и любых драйверов (пакет `usb`, реализует тот же
     стандарт WebUSB, что браузер использует в Velora).
   - **Bluetooth** — через виртуальный COM-порт, который Windows создаёт при
     Bluetooth-сопряжении с принтером (пакет `serialport`).
4. Помечает заказ как напечатанный, чтобы при перезапуске программа не
   печатала старые чеки повторно (кроме заказов младше 2 часов — их
   допечатает, если компьютер был выключен).

## Проблемы

**Чек не печатается**
- Проверьте в `agent.log` (появляется рядом с `Menora.vbs` после первого
  запуска) — там видна точная ошибка.
- Проверьте, что принтер включён, в нём есть бумага и (для варианта
  «Windows») он не показывает ошибку в Windows (жёлтый треугольник на
  значке принтера).
- Для варианта «Windows» — попробуйте распечатать любой обычный документ
  через этот же принтер из самой Windows; если это тоже не работает, дело не
  в программе.
- Для варианта «USB» — убедитесь, что принтер выбран верно в списке (у
  дешёвых принтеров может быть несколько USB-интерфейсов, не все из них —
  принтер).
- Для варианта «Bluetooth» — принтер должен быть уже сопряжён с компьютером
  через обычные Bluetooth-настройки Windows *до* того, как он появится в
  списке устройств программы.
- Откройте окно настроек (см. «Как снова открыть окно настроек» выше) →
  выберите принтер/устройство заново → «Тестовая печать».

**Кириллица печатается кракозябрами**

Дешёвые ESC/POS-принтеры используют разные кодовые страницы для кириллицы.
Откройте окно настроек и смените значение в выпадающем списке «Кодировка
кириллицы» — там перечислены все варианты, которые бывают у таких
принтеров (PC866, Windows-1251, PC855, украинская, казахская и т.д.).
Нажмите «Тестовая печать» после каждой смены, чтобы сразу увидеть, подошла
ли кодировка. По умолчанию используется `PC866_CYRILLIC2` — самый
распространённый вариант.

**Чек не пришёл сразу после первого запуска/переустановки**

Программа подхватывает заказы младше 2 часов, если была выключена. Более
старые неотпечатанные заказы придётся посмотреть в кабинете вручную — это
осознанное ограничение, чтобы при первом запуске не распечатался весь архив
заказов.

## Если печатающих точек несколько (например, бар и кухня)

Скопируйте всю папку во вторую папку на компьютере у второго принтера и
запустите `Menora.vbs` — при первом запуске окно настройки просто спросит
данные заново (эта копия сохранит свой собственный `config.json` с другим
принтером). Оба экземпляра независимо друг от друга подпишутся на один и
тот же поток заказов.

## Для разработчиков

Исходники — `agent.js` (логика печати/подписки на заказы), `printer-transport.js`
(три способа достучаться до принтера — Windows/USB/Bluetooth, подробности в
комментариях наверху файла), `setup-wizard.js` (старый CLI-мастер, оставлен
как резервный путь при прямом запуске `menora-print.exe` без `Menora.vbs`),
`gui/setup-gui.ps1` (настоящее окно на WinForms — то, что реально видит
владелец заведения).

`usb` и `serialport` — нативные npm-модули (со скомпилированным
`.node`-биндингом под Windows x64). Node SEA не умеет встраивать такое
внутрь `.exe`, поэтому `build-exe.js` копирует их отдельной папкой
`dist/node_modules/` рядом с `menora-print.exe` — эта папка обязательна,
без неё не заработают варианты «USB» и «Bluetooth» (вариант «Windows»
от неё не зависит).

Запуск без сборки в exe:

```bash
npm install
npm run test-print   # тестовая печать, спросит принтер при первом запуске
npm start             # обычный запуск
```

В режиме разработки конфиг можно также задать через `.env` (см.
`.env.example`) — переменные окружения имеют приоритет над `config.json`.

Собрать всё заново после изменений в коде:

```bash
npm run build
```

Соберёт через встроенный в Node механизм Single Executable Applications
(бандл — `esbuild`, инъекция в exe — `postject`) `menora-print.exe`, и
скопирует `Menora.vbs`, `gui/setup-gui.ps1`, `node_modules/` (нативные
`usb`/`serialport`) и `install-autostart.bat` (устаревший — GUI теперь сам
предлагает автозапуск галочкой, но .bat оставлен как ручной запасной путь)
в `dist/` — это и есть вся папка, которую нужно отдать владельцу заведения.
Интернет для сборки не нужен — используется Node, уже установленный на этой
машине.

**Важные нюансы, если правите `gui/setup-gui.ps1` или `Menora.vbs`:**
- Оба файла должны быть сохранены в **UTF-8 с BOM** — Windows PowerShell 5.1
  и старый cscript/wscript без BOM читают кириллицу в них как кракозябры
  (в случае .ps1 это ломает реальные строки в интерфейсе; в случае .vbs
  особенно опасно для *значений переменных с кириллицей*, если такие
  появятся — сейчас в .vbs кириллица только в комментариях, поэтому он
  работает и без BOM, но лучше не рисковать).
- `$ConfigPath`/`$AgentExe` в `setup-gui.ps1` считаются на уровень выше
  `gui/` (там, где лежит `menora-print.exe`) — это должно совпадать с тем,
  куда `agent.js` кладёт `config.json` (`path.dirname(process.execPath)`).
- `node --experimental-sea-config` падает (segfault), если текущая папка
  содержит не-ASCII символы (у нас — "Рабочий стол") — `build-exe.js` уже
  обходит это, всегда собирая SEA-блоб во временной ASCII-папке.
